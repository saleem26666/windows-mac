# Windows to Mac user guide (M1)

You already know how to use a computer. macOS does the same work as Windows — files, email, browser, office apps — with different names and a few new habits. This guide is for someone moving from Windows to an Apple silicon Mac (M1). Read it once, then keep it nearby for the first week.

---

## The one rule that saves the first week

On Windows, the **X** button usually closes the program.

On a Mac, the **red circle** (top left of the window) closes **that window**. The app often keeps running. Look at the **Dock** — the row of icons, usually at the bottom of the screen. A small **dot** under an icon means the app is still open.

- Close one window: red button, or **Command (⌘) + W**
- Quit the whole app: **Command (⌘) + Q**
- Or right-click the Dock icon and choose **Quit**

This is not a bug. Think of an app as a house: you can close a room without leaving the house.

## Mouse, trackpad, and opening files

**To open a file or folder: double-click.** Same as Windows. One click selects. Two clicks open. Documents, photos, folders — all the same.

| What you want | On Windows | On a Mac |
| --- | --- | --- |
| Open a file or folder | Double-click | Double-click |
| Select | Single click | Single click |
| Right-click menu | Right mouse button | **Two-finger click** on the trackpad, or hold **Control** and click |
| Preview without opening | Preview pane | Select the file, press **Space** (Quick Look). Space or Esc closes it. |
| Rename | F2 | Click once to select, then press **Return**. Type. Press Return again. |
| Scroll | Mouse wheel | Two fingers on the trackpad |
| Zoom | Ctrl + wheel | Pinch with two fingers |
| Drag | Click, hold, move | Same |

A USB mouse works like Windows: the right button is right-click.

**Make the trackpad feel familiar**

1. Open **System Settings** (Apple menu, top left → System Settings).
2. Open **Trackpad**.
3. Turn on **Tap to click** if you want a light tap instead of a firm press.
4. Set **Secondary click** to **Click with two fingers**.
5. If the page moves the “wrong” way when you scroll, turn **Natural scrolling** off. Windows users often prefer it off.

## Keyboard: Ctrl becomes Command

The **Command** key sits next to the spacebar. It has the **⌘** symbol. Almost every shortcut you remember with **Ctrl** now uses **Command**.

| Windows | Mac | What it does |
| --- | --- | --- |
| Ctrl | Command ⌘ | Copy, paste, save, quit |
| Alt | Option ⌥ | Extra characters and extra shortcuts |
| Windows key | Command ⌘ | There is no Windows key on a Mac keyboard |
| Backspace | Delete | Deletes to the left |
| Delete (forward) | **Fn + Delete** | Deletes to the right |
| Home / End | **⌘ Left / ⌘ Right** | Start or end of the line |
| Ctrl + Home / End | **⌘ Up / ⌘ Down** | Start or end of the document |
| Ctrl + Left / Right | **Option + Left / Right** | Jump by word |
| Print Screen | **⌘ Shift + 3 / 4 / 5** | Screenshots (see below) |

If you plug in a **Windows keyboard**, the Windows key acts as Command and Alt acts as Option. If the keys feel swapped, go to **System Settings → Keyboard → Keyboard Shortcuts → Modifier Keys** and remap them.

| Windows | Mac | Note |
| --- | --- | --- |
| File Explorer | **Finder** | Smiling face on the left of the Dock |
| Taskbar | **Dock** | Open apps sit here |
| Start menu | **Spotlight** + **Launchpad** | Press **⌘ Space** to search |
| System tray | Menu bar, top right | Wi-Fi, battery, clock, Control Centre |
| Recycle Bin | **Trash** | Right side of the Dock |
| Control Panel / Settings | **System Settings** | Apple menu → System Settings |
| Task Manager | **Activity Monitor**, or **Force Quit** | **⌘ Option + Esc** |
| This PC / C: drive | **Macintosh HD** and your **Home** folder | You live in `/Users/yourname` |
| Program Files | **Applications** | In Finder: **⌘ Shift + A** |
| `.exe` installer | `.dmg` or `.pkg` | Open the disk image, drag the app to Applications |

**Spotlight is your new Start menu.** Press **Command + Space**, type the app or file name, press **Return**. After two days this is faster than hunting icons.

## Files and disks

**Finder** is File Explorer. Click the smiling face on the left of the Dock.

Your **Home** folder is the Mac version of `C:\Users\You`. Inside it: Desktop, Documents, Downloads, Pictures, Movies.

There is **no C: drive letter**. The internal disk is **Macintosh HD**. A USB stick appears on the Desktop and in the Finder sidebar. **Eject** it before unplugging: click the eject icon, or select the disk and press **⌘ E**.

**AirDrop** (in the Finder sidebar) sends a file to a nearby iPhone or Mac without a cable. Both devices need Wi-Fi and Bluetooth on.

## Installing apps

Apps live in **Applications**, not Program Files.

- **App Store:** Apple menu nearby, or Spotlight “App Store”.
- **Website download:** often a **`.dmg`**. Open it. Drag the app icon onto the **Applications** folder. Then eject the disk image (like removing a USB stick).
- Some installers are **`.pkg`**: double-click and follow the steps.

**Uninstall:** open Applications, drag the app to **Trash**, then empty Trash. A few apps have their own uninstaller; those will say so.

**Pin to Dock:** drag the app onto the Dock, or right-click the icon while it is open → **Options → Keep in Dock**.

**Menus** sit at the **top of the screen**, not inside the window. Click the app name (Finder, Safari, Word) for Settings, Hide, and Quit.

The **green** button is usually **full screen**. Hold **Option** and click green if you only want a larger window without leaving the desktop.

## What the M1 chip changes

M1 is **Apple silicon** (ARM), not Intel. The machine stays cool, wakes at once, and the battery often lasts a full workday.

**Rosetta.** If you open an older app built for Intel, macOS may ask to install **Rosetta**. Choose **Install**. It translates those apps so they run on M1. When a download page offers **Apple silicon** or **Universal**, pick that.

**No Boot Camp.** Older Intel Macs could reboot into Windows. **M1 cannot.** If you still need a Windows program, look for a Mac version first. If none exists, a **virtual machine** (Parallels, UTM) is the path — slower and more work than the old dual-boot.

**Ports.** Many M1 Macs are **USB-C only**. Keep a small hub for USB-A pendrives and HDMI monitors.

**“Unidentified developer.”** For an app you trust, open **System Settings → Privacy & Security**, scroll down, click **Open Anyway**.

Office, Chrome, Edge, WhatsApp, Zoom, and VS Code all have M1-ready builds. Install from the official site or the App Store.

## Trackpad gestures

Turn these on or off in **System Settings → Trackpad**. Learn them slowly.

| Gesture | Result |
| --- | --- |
| Two-finger scroll | Move a page |
| Two-finger click | Right-click |
| Pinch | Zoom photos, maps, PDFs |
| Two-finger swipe left / right | Back and forward in Safari or Finder |
| Three-finger swipe up | **Mission Control** — every open window |
| Three-finger swipe left / right | Move between full-screen apps and desktops |
| Thumb + three fingers pinch in | **Launchpad** (all apps, like a Start grid) |
| Thumb + three fingers spread | Show the Desktop |

## A calm first hour

1. Connect Wi-Fi from the icon at the **top right**.
2. Sign in with an Apple ID if you want iCloud (optional on day one).
3. Turn on **Tap to click** and **two-finger Secondary click**.
4. Practise **⌘ Space** — type an app name, press Return.
5. Open Finder. Find **Downloads** and **Documents**.
6. Take a screenshot with **⌘ Shift + 4**. Look on the Desktop.
7. Double-click a file to open it. Rename another with **Return**.
8. Close a window with the red button. Notice the app is still in the Dock. Quit it with **⌘ Q**.

## Common problems

**The app “disappeared” after the red button.** It is still running. Click its Dock icon, or press **⌘ Tab**. Next time use **⌘ Q** if you want it fully closed.

**The app is frozen.** Press **⌘ Option + Esc**, select the app, **Force Quit**. This is End task.

**Cannot find a download.** Finder → **Downloads**, or **⌘ Option + L**. Also check the browser’s Downloads button.

**Need an old Windows-only program.** Search for a Mac version. If there is none, M1 uses a virtual machine, not Boot Camp.

**Trackpad feels hard.** System Settings → Trackpad → **Tap to click**.

**Copy and paste “do not work.”** You are still pressing Control. Use **Command**.

## First-week practice

- [ ] Tap to click and two-finger right-click
- [ ] Spotlight: ⌘ Space, type, Return
- [ ] Open a file with a double-click
- [ ] Close a window (red), then quit the app (⌘ Q)
- [ ] Screenshot with ⌘ Shift + 4
- [ ] Rename a file with Return
- [ ] Quick Look with Space
- [ ] Install Rosetta if macOS asks
- [ ] Keep everyday apps in the Dock
- [ ] Lock: Control + ⌘ Q · Force Quit: ⌘ Option + Esc

After a week the new names stop feeling new. The machine is the same idea as Windows. You just have a better map.
