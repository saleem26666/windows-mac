# Windows → Mac (M1)

Printable user guide for switching from Windows to an Apple silicon Mac.

| Language | Word | PDF |

Open the PDF to read or print. Open the Word file if you want to edit or add your own notes.

**Shortcut reminder:** almost every Windows **Ctrl** shortcut uses **Command (⌘)** on a Mac. Double-click still opens a file.
